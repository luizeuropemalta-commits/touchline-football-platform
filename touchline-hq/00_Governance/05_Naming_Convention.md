# Naming Convention

Version: 0.1  
Author: Touchline Executive Documentation Board  
Last Updated: 2026-06-26  
Status: Active  
Dependencies: Touchline HQ README, 14_Development  
Future Related Documents: Code Naming Rules, Database Naming Rules, Product Naming Rules

## Folder Naming

Use numbered folders with clear capitalized names:

```text
00_Governance
01_Executive
02_Product
```

## Document Naming

Use numbered Markdown files:

```text
01_Document_Name.md
02_Document_Name.md
```

## Product Naming

Use consistent names:

- Touchline Professional
- Touchline Fantasy
- Touchline HQ
- Football Search
- Transfer Center
- Club Network
- Player Portfolio

## Archive Naming

Archived documents must keep their original name when possible and may include a date prefix:

```text
2026-06-26_Old_Search_Strategy.md
```
