This is an intentional fail-closed control, but it means current Preview cannot be the product-validation route while those variables are scoped to Preview. Do **not** bypass the isolation guard or copy production credentials into a test environment.

## Local recovery candidate — release command gate

The local candidate now adds `verify:release` and `vercel-build` to
`package.json`. `vercel-build` runs, in order, non-incremental typechecking,
lint, the complete Node test suite and the static readiness contract before
`next build --webpack`. The accompanying source-contract test prevents a
future edit from silently reverting Vercel to an unchecked build.

This is only a versioned local safeguard. It did not edit the Vercel project,
change the configured deployment, read a secret or promote a deployment. The
external DNS, Preview-isolation and deployment-SHA gates above still apply.
