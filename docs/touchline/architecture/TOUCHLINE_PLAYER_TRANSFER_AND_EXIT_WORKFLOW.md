# Player transfer and exit workflow

When canonical roster data shows that a player leaves the Premier League competition or changes active membership, the publication policy no longer validates the record and the card immediately disappears from game-card surfaces.

- `inactive_in_competition`: player remains as historical football data but is not a selectable/current game card.
- `archived`: terminal publication state after the approved retention decision.
- transfer/re-entry: requires the new canonical active membership and a new review before publication.

No player deletion, inventory rewrite, contract rewrite or public placeholder is used to represent an exit.
